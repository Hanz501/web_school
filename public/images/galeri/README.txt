Folder ini digunakan untuk menyimpan foto-foto galeri fasilitas dan karya sekolah:

Contoh nama file yang didukung:
1. lab-imac.jpg (Fasilitas Lab Multimedia / DKV)
2. data-center.jpg (Fasilitas Cloud Server / TKJ)
3. software-house.jpg (Fasilitas Software House / RPL)
4. mini-bank.jpg (Fasilitas Digital Banking / AKL)
5. smart-library.jpg (Perpustakaan Digital)
6. auditorium.jpg (Auditorium & Gedung Utama)

Format yang didukung: .jpg, .jpeg, .png, .webp
Pemanggilan di CodeIgniter 4: base_url('images/galeri/nama-foto.jpg')
